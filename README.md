執行人員：鄭合汶
技術領域：數據工程 (ETL)、商業智慧 (BI)、雲端數據整合
===========================================================

一、 專案核心目標 (Project Objective)
-----------------------------------------------------------
本專案旨在分析台灣 112 年度 A1 類（死亡）交通事故，透過 Python 進行
數據清洗與特徵工程，並利用 Power BI 建構動態分析儀表板，藉此找出
「道路型態」、「高危險族群」與「肇事主因」之間的深層關聯。

二、 技術實作流程 (Technical Workflow)
-----------------------------------------------------------
1. 資料獲取與清洗 (Python ETL)：
   - 編碼修正：處理原始 CSV 之 utf-8-sig 格式，確保中文字元正確顯示。
   - 特徵工程：
     * 年齡分組：將連續數值轉換為「青少年、成年、高齡者」類別。
     * 時段切分：定義清晨、日間、傍晚、深夜，分析事故時間趨勢。
   - 座標處理：確保經緯度數據符合 WGS84 標準，供座標軸定位使用。

2. Power BI 建模與視覺化：
   - AI 分析樹 (Decomposition Tree)：由道路型態向下鑽取車種與年齡層。
   - 散布圖空間分析 (Scatter Plot Analysis)：
     * 取代傳統地圖功能，以經度為 X 軸、緯度為 Y 軸繪製事故點。
     * 透過點位密度直觀呈現全台事故熱點分布，避開系統環境權限限制。
   - 互動式 UX 設計：
     * 實作「書籤 (Bookmarks)」功能，建立一鍵切換視角的導覽按鈕。
     * 建立「重設 (Reset)」按鈕，優化使用者篩選體驗。

3. 雲端架構與佈署 (Cloud Integration)：
   - 資料遷移：將靜態檔案託管於雲端平台（OneDrive/GitHub），實現遠端連線。
   - Web 數據對齊：手動修正 Power Query 中的分隔符號（Delimiter）與
     欄位標題映射（Schema Mapping），解決雲端讀取時的資料錯位問題。

三、 關鍵問題排除紀錄 (Troubleshooting Log)
-----------------------------------------------------------
1. [環境限制]：地圖功能因組織帳號安全性限制 (MapVisualNotEnabled) 停用。
   -> 解決方案：開發「座標散布圖」替代方案，利用 X-Y 軸重建空間分佈，
      維持視覺化分析的完整性。
2. [資料損壞]：切換雲端來源後，發生「找不到資料行 Date」報錯。
   -> 解決方案：進入 Power Query 修正分隔符號由 Tab 改為 Comma，
      並重新定義標頭升階與欄位名稱映射。
3. [網路限制]：學校環境防火牆封鎖 TDX API 動態爬取。
   -> 解決方案：改採政府開放平台之靜態資料，透過雲端 URL 達成
      跨環境數據連線與半自動化更新。

四、 專案洞察結論 (Key Insights)
-----------------------------------------------------------
1. 事故熱點：透過散布圖觀察，平面交叉路口為 A1 事故最高發區域。
2. 弱勢分析：機車與慢車佔死亡事故絕大多數，高齡族群在日間路口之
   反應缺失為顯著風險指標。
3. 政策建議：針對熱點路口優化左轉保護時相，並加強銀髮族防禦駕駛宣導。
